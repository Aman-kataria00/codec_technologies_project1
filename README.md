Customer Churn Prediction
Project 1 – Internship at Codec Technologies
📌 Project Overview
Customer churn prediction helps identify customers who are likely to stop using a service. In this project, a telecom dataset is analyzed to understand customer behavior and predict churn using machine learning classification models.
This project was completed as Project 1 of my internship at Codec Technologies.
________________________________________
🎯 Objective
•	To analyze telecom customer data
•	To identify churn patterns using Exploratory Data Analysis (EDA)
•	To build machine learning models that predict customer churn
•	To evaluate model performance using standard metrics
________________________________________
📊 Dataset
•	Telecom customer usage dataset
•	Contains call usage, data usage, recharge amount, ARPU, and customer activity details
•	Real-world, high-dimensional dataset
________________________________________
🔍 Exploratory Data Analysis (EDA)
•	Data understanding and cleaning
•	Missing value handling
•	Distribution analysis (ARPU, call usage, data usage)
•	Monthly trend analysis
•	Visualizations using Matplotlib
________________________________________
🤖 Machine Learning Models Used
•	Logistic Regression
•	Random Forest Classifier
________________________________________
📈 Model Evaluation Metrics
•	Accuracy
•	Recall (important for identifying churn customers)
•	ROC-AUC Score
•	ROC Curve visualization
________________________________________
🛠 Tools & Technologies
•	Python
•	Jupyter Notebook
•	Pandas, NumPy
•	Scikit-learn
•	Matplotlib
________________________________________
✅ Conclusion
The project successfully identifies customers who are likely to churn by analyzing their usage behavior. This approach can help telecom companies take proactive retention measures.
